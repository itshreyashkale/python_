# DSA Foundations

This section covers the concepts needed to understand, design, analyze, and improve algorithms before moving into individual data structures and algorithmic techniques.

The material is divided into focused chapters so each subject can be read and maintained independently.

## Chapters

| Chapter | Subject | Coverage |
|---|---|---|
| 1 | [Data Structures and Algorithms](01_data_structures_and_algorithms.md) | Data structures, algorithms, and how they work together |
| 2 | [Understanding and Solving Problems](02_problem_solving.md) | Inputs, outputs, constraints, examples, edge cases, and solution planning |
| 3 | [Brute Force and Optimization](03_brute_force_and_optimization.md) | Candidate checking, Two Sum, optimization, and time-space trade-offs |
| 4 | [Time Complexity and Big O](04_time_complexity.md) | Growth rates, loop analysis, best/average/worst cases, and Big O simplification |
| 5 | Space Complexity | Auxiliary space and memory growth — covered in a forthcoming chapter |

## Learning Sequence

1. Understand data structures and algorithms.
2. Learn how to analyze a problem before coding.
3. Establish a straightforward solution, then consider optimization.
4. Analyze how an algorithm's work grows with input size.
5. Analyze additional memory usage and time-space trade-offs.

## Scope

This section contains foundational reference material. Topic-specific data structure chapters and problem solutions are maintained separately in their respective sections of the repository.
